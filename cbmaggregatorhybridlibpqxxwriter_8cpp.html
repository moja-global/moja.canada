Detailed Description

The CBMAggregatorHybridLibPQXXWriter module writes the stand-level information gathered by CBMAggregatorLandUnitData into a PostgreSQL database. It is designed mainly for distributed runs where the simulation is divided up and each portion of work is loaded into a separate set of tables before being merged together with a post-processing script, although this module can also be used for a standard simulation
